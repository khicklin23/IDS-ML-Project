LEARNING FROM MISTAKES

How does a network improve?

1

Compare with the right answer

During training, an example comes with a correct answer. A loss function measures how far the network’s prediction is from that answer.

2

Trace the influence backward

Backpropagation works backward through the connected neurons. It calculates how a small change to each connection’s weight would affect the error. That sensitivity is called a gradient.

3

Adjust, then try again

An optimizer uses those gradients to make small weight changes in a direction that should reduce the error. Repeating this across many examples gradually improves the network’s predictions.

The network does not need to identify one “bad neuron.” It measures how connections throughout the network influence the error and adjusts them together. Separate, unseen examples check whether the improvement carries over.
